Task Description:

The task I performed was the design and development of a Portfolio Website using HTML and CSS. The primary objective of this task was to create a personal website that showcases my skills, projects, and contact details in a professional and visually appealing format. A portfolio website serves as a digital resume, helping potential employers, collaborators, or clients to quickly view one’s background and previous work.

The portfolio is divided into four main sections: Header, Navigation, About, Projects, and Contact. The header section displays the name and tagline to introduce the portfolio. The navigation bar provides links to different sections of the page, allowing smooth navigation. The About section highlights a brief description of my passion for web development and learning new technologies. The Projects section is designed to display key projects completed, including a Chat Application, a Quiz App with Timer, and an E-Learning Platform. Each project is explained in short descriptions, making it easy for viewers to understand the type of work done. Finally, the Contact section provides direct communication details, such as email, for easy outreach. A footer at the bottom contains copyright details.

During development, the HTML structure was used to divide the website into sections and provide semantic meaning. Elements such as

, and were used to organize content properly. Inside each section, headings, paragraphs, and links were included to make the website informative and accessible.
For styling, CSS was used to enhance the design and layout of the portfolio. The header was styled with a blue background and white text to make it stand out. The navigation bar used flexbox for alignment, ensuring a clean horizontal menu that adapts to different screen sizes. Hover effects were applied to navigation links, changing background colors for interactivity. The Projects section was styled with light gray backgrounds and rounded edges to highlight each project separately. The footer used a dark background with white text, ensuring good readability. A media query was also included to make the navigation responsive, switching to a column layout on smaller screens.

This task provided an opportunity to practice responsive web design principles, layout structuring, and styling for professional presentation. It also reinforced the importance of having an online portfolio as a way to showcase technical abilities in web development.
